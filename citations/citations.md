There comes a time when, in the developement of an algorithm, outside sources must be used.
As references, examples, or explanations of a concept.
These sources are valuable, but keeping track of them can be difficult.
The purpose of this file is to list out citations.
Whitepapers, blog posts, potentially even videos that were or can be useful for further development.
I don't think we'll remain disiplined enough to refer to these citations in the code (but we can try!).
Instead, I want this to serve as a file to find a quick link to a source (downloading the files and hosting them here might be a copyright issue).
